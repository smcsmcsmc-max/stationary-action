📐 변분법: “경로 전체”를 바꿔 가며 최적을 찾는 수학

정상 작용 원리를 수학적으로 뒷받침하는 도구예요. 식은 천천히, 하나씩 풀어 갈게요.

3줄 요약

  1. 변분법은 함수(경로) 하나를 넣으면 숫자 하나가 나오는 “범함수”의 최솟값·정상점을 찾는 수학이에요.
  2. 경로를 아주 조금 흔들어도 값이 변하지 않을 조건(첫 번째 변분 $=0$)을 정리하면 오일러–라그랑주 방정식 $\dfrac{d}{dx}\dfrac{\partial F}{\partial y'} - \dfrac{\partial F}{\partial y} = 0$ 이 나와요.
  3. 이 식 하나로 직선(최단경로), 사이클로이드(최단 시간 곡선), 뉴턴의 $F = ma$가 모두 나오고, 컴퓨터로는 경로를 점으로 쪼개 경사하강법으로도 풀 수 있어요.

1먼저 알아둘 것: 함수와 범함수

  • 함수는 숫자를 넣으면 숫자가 나오는 규칙이에요. 예: $f(x) = x^2$에 $3$을 넣으면 $9$.
  • 범함수(functional)는 함수(=경로, 곡선)를 통째로 넣으면 숫자 하나가 나오는 규칙이에요. 대괄호로 $J[y]$처럼 써요. 예: 곡선의 길이
    $$J[y] = \int \sqrt{1 + y'^2}\,dx$$
    $y' = \dfrac{dy}{dx}$는 곡선의 기울기예요. 곡선 모양이 달라지면 길이도 달라지죠. 그래서 “곡선 → 길이(숫자)”인 범함수예요.
  • 앞 페이지의 작용 $S$도 범함수예요. 경로 $y(t)$를 넣으면 숫자 $S$가 나와요.

보통 함수의 최솟값은 $f'(x) = 0$인 점에서 찾죠. 범함수에서는 “$x$를 조금 움직이기” 대신 “경로를 조금 흔들기”를 해요. 그게 다음 장의 주제예요.

2첫 번째 변분이란?

후보 경로 $y(x)$에 작은 흔들림을 더해 볼게요.

$$y_\varepsilon(x) = y(x) + \varepsilon\,\eta(x)$$$\eta$(에타)는 흔들림의 모양, $\varepsilon$(엡실론)은 흔들림의 크기를 정하는 작은 수

양 끝점은 고정이라서 $\eta(a) = \eta(b) = 0$이어야 해요. 이제 $J(\varepsilon) = J[y + \varepsilon\eta]$는 $\varepsilon$ 하나만의 평범한 함수가 돼요. 그래서 평범한 미분을 쓸 수 있어요.

$$\delta J = \left.\frac{dJ}{d\varepsilon}\right|_{\varepsilon = 0}$$첫 번째 변분(first variation): 흔들림을 “1차로” 느끼는 정도

$y$가 정상점(최솟값 포함)이라면 어떤 흔들림 $\eta$를 줘도 $\delta J = 0$이어야 해요. 골짜기 바닥에서는 어느 방향으로 살짝 움직여도 높이가 1차로는 안 변하는 것과 같아요. 이 $\delta J$를 “$\eta$ 앞의 계수”로 읽은 것이 범함수 도함수 $\dfrac{\delta J}{\delta y}$예요: $\delta J = \displaystyle\int \frac{\delta J}{\delta y}\,\eta\,dx$.

3오일러–라그랑주 방정식, 한 단계씩 유도하기

범함수가 $J[y] = \displaystyle\int_a^b F(x, y, y')\,dx$ 꼴이라고 해 볼게요. ($F$는 $x$, $y$, $y'$로 이루어진 식. 작용에서는 $F$가 $L = T - V$예요.)

단계 1 — 흔든 경로를 넣고 $\varepsilon$로 미분

$$\left.\frac{dJ}{d\varepsilon}\right|_{\varepsilon=0} = \int_a^b \left[\frac{\partial F}{\partial y}\,\eta + \frac{\partial F}{\partial y'}\,\eta'\right] dx$$합성함수의 미분(연쇄법칙): $y$가 $\eta$만큼, $y'$가 $\eta'$만큼 변하니까 두 항이 생겨요. $\partial$는 “다른 변수는 고정하고 한 변수로만 미분”이라는 기호예요.

단계 2 — 둘째 항에 부분적분

$\eta'$가 거슬리니 $\eta$만 남기고 싶어요. 부분적분 공식 $\int u\,v' = [uv] - \int u'\,v$를 쓰면

$$\int_a^b \frac{\partial F}{\partial y'}\,\eta'\,dx = \left[\frac{\partial F}{\partial y'}\,\eta\right]_a^b - \int_a^b \frac{d}{dx}\!\left(\frac{\partial F}{\partial y'}\right)\eta\,dx$$

단계 3 — 경계항이 사라진다

양 끝에서 $\eta(a) = \eta(b) = 0$이므로 대괄호 항은 $0$이에요. 그래서

$$\delta J = \int_a^b \left[\frac{\partial F}{\partial y} - \frac{d}{dx}\!\left(\frac{\partial F}{\partial y'}\right)\right]\eta\,dx = 0$$

단계 4 — 기본 보조정리

기본 보조정리: 연속함수 $g(x)$가 끝점에서 $0$인 모든 $\eta$에 대해 $\displaystyle\int g\,\eta\,dx = 0$이면 $g(x) \equiv 0$이에요. 이유는 간단해요. 어떤 점 $x_0$에서 $g(x_0) \gt 0$이라면, $x_0$ 근처에서만 양수이고 나머지는 $0$인 작은 “혹” 모양 $\eta$를 고를 수 있어요. 그러면 적분이 양수가 되어 모순이죠($g \lt 0$도 마찬가지).

결과

$$\frac{\partial F}{\partial y} - \frac{d}{dx}\!\left(\frac{\partial F}{\partial y'}\right) = 0$$오일러–라그랑주(Euler–Lagrange) 방정식

역학에서는 독립변수가 시간 $t$, 경로가 $q(t)$, $F$가 $L(q, \dot q, t)$예요. 그래서 $\dfrac{\partial L}{\partial q} - \dfrac{d}{dt}\dfrac{\partial L}{\partial \dot q} = 0$ ($\dot q = dq/dt$)로 써요.

4예제 (a) 두 점 사이의 최단경로는 직선

길이 범함수의 $F$는 $F = \sqrt{1 + y'^2}$예요. $y$가 직접 안 들어 있으니 $\dfrac{\partial F}{\partial y} = 0$이고, $\dfrac{\partial F}{\partial y'} = \dfrac{y'}{\sqrt{1 + y'^2}}$예요. 오일러–라그랑주는

$$\frac{d}{dx}\!\left[\frac{y'}{\sqrt{1 + y'^2}}\right] = 0 \;\Longrightarrow\; \frac{y'}{\sqrt{1 + y'^2}} = \text{상수} \;\Longrightarrow\; y' = \text{상수}$$

기울기가 일정한 곡선은 직선이에요. 확인해 볼까요? 점 $(0,0)$에서 $(1,1)$까지, 직선 $y = x$에 사인 모양 흔들림 두 개를 더해 보세요.

5예제 (b) 최단 시간 곡선(브라키스토크론)

높은 점 A에서 공을 가만히 놓아 낮은 점 B까지 미끄러뜨릴 때, 어떤 곡선이 가장 빨리 도착할까요? 직선이 가장 짧긴 하지만 가장 빠르진 않아요. 처음에 가파르게 내려가 속도를 붙이는 게 이득이거든요.

A를 원점으로, 아래쪽을 $+y$로 잡아요. 에너지 보존으로 $y$만큼 내려온 공의 속력은 $v = \sqrt{2gy}$이고, 짧은 길이 $ds$를 지나는 시간은 $ds/v$예요. 그래서 걸리는 시간은 범함수

$$T[y] = \int \frac{\sqrt{1 + y'^2}}{\sqrt{2 g y}}\,dx$$

예요. 여기서 $F$에는 $x$가 직접 들어 있지 않아서 오일러–라그랑주를 한 번 적분한 벨트라미 항등식 $F - y'\dfrac{\partial F}{\partial y'} = \text{상수}$를 쓸 수 있어요. 풀면 사이클로이드(굴러가는 바퀴 테두리의 한 점이 그리는 곡선)가 나와요.

$$x = r(\theta - \sin\theta), \qquad y = r(1 - \cos\theta)$$$\theta$는 바퀴가 구른 각도, $r$은 바퀴 반지름. 끝점 B에 맞게 $r$과 $\theta_B$를 정해요. 걸리는 시간은 $\theta_B\sqrt{r/g}$

아래에서 A$(0, 0)$ → B$(2\ \text{m},\ 1\ \text{m})$로 내려가는 세 경로를 비교해 보세요. 빨간 곡선은 $y = (x/2)^p$ 꼴이고 $p$로 모양을 바꿔요($p = 1$이면 직선, $p \lt 1$이면 처음이 가파른 곡선). 시간은 위 범함수 $T[y]$를 수치 적분해서 구해요.

6예제 (c) 라그랑지안에서 $F = ma$ 되찾기

한 방향으로 움직이는 질량 $m$인 입자를 생각해요. $L = T - V = \tfrac12 m\dot x^2 - V(x)$. 오일러–라그랑주($\dfrac{\partial L}{\partial x} - \dfrac{d}{dt}\dfrac{\partial L}{\partial \dot x} = 0$)의 두 조각은

$$\frac{\partial L}{\partial \dot x} = m\dot x, \qquad \frac{\partial L}{\partial x} = -V'(x)$$

이니까 식에 넣으면 $-V'(x) - \dfrac{d}{dt}(m\dot x) = 0$, 즉

$$m\ddot x = -V'(x) = F$$뉴턴의 운동법칙! (힘 $F$는 위치에너지를 내리막 방향으로 미분한 것)
  • 자유입자 ($V = 0$): $m\ddot x = 0$. 가속도가 $0$이니 등속직선운동이에요.
  • 용수철 ($V = \tfrac12 k x^2$): $m\ddot x = -kx$. 단순조화진동이에요. 해는 $x = A\cos(\omega t + \varphi)$, $\omega = \sqrt{k/m}$.
  • 중력 ($V = mgy$): $\ddot y = -g$. 앞 페이지의 포물선이 바로 이 식의 해예요.

7컴퓨터로 해 보기: 경로를 점으로 쪼개 경사하강법

컴퓨터는 연속 경로를 다룰 수 없어서 $N$개 구간으로 쪼개요. 시간 $0$~$2$초를 같은 간격 $\Delta t$로 나누고, 각 점의 높이 $y_0, y_1, \dots, y_N$를 변수로 삼아요(양 끝 $y_0 = y_N = 0$ 고정). 작용은 이렇게 근사해요.

$$S \approx \sum_{i=0}^{N-1} \Delta t\left[\frac{m}{2}\left(\frac{y_{i+1} - y_i}{\Delta t}\right)^2 - m g\,\frac{y_i + y_{i+1}}{2}\right]$$

이제 $S$는 $N - 1$개 변수의 평범한 함수예요. 평범한 함수니까 경사하강법(기울기의 반대 방향으로 조금씩 내려가기)을 쓸 수 있어요. 각 점의 기울기는

$$\frac{\partial S}{\partial y_i} = \frac{m}{\Delta t}\left(2y_i - y_{i-1} - y_{i+1}\right) - m g\,\Delta t$$

이고, 이 값이 $0$이라는 것은 $\dfrac{y_{i+1} - 2y_i + y_{i-1}}{\Delta t^2} = -g$, 즉 “가속도 $= -g$”의 이산 버전이에요. 오일러–라그랑주 방정식이 그대로 나타나죠!

9용어 정리

함수 / 범함수
함수는 숫자 → 숫자, 범함수는 함수(경로) → 숫자.
변분(variation)
경로를 조금 바꾸는 것, 또는 그에 따른 범함수의 변화.
첫 번째 변분 $\delta J$
흔들림 크기 $\varepsilon$에 대한 $J$의 1차 변화율. 정상점에서 $0$.
흔들림 $\eta$
경로에 더하는 작은 모양. 끝점에서는 $0$.
부분적분
미분을 곱의 다른 쪽으로 옮기는 적분 기술. $\int u v' = [uv] - \int u' v$.
기본 보조정리
모든 $\eta$에 대해 $\int g\eta = 0$이면 $g = 0$.
오일러–라그랑주 방정식
정상점이 되기 위한 조건식. $\dfrac{\partial F}{\partial y} - \dfrac{d}{dx}\dfrac{\partial F}{\partial y'} = 0$.
벨트라미 항등식
$F$가 $x$를 직접 포함하지 않을 때 $F - y'\dfrac{\partial F}{\partial y'} = \text{상수}$.
사이클로이드
굴러가는 바퀴 테두리 한 점의 자취. 최단 시간 곡선.
경사하강법
기울기의 반대 방향으로 조금씩 움직여 최솟값을 찾는 방법.
구속조건 / 라그랑주 승수
문제에 붙는 제약, 그리고 이를 다루는 도우미 변수 $\lambda$.
